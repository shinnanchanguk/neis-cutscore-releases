NEIS 분할점수 계산기 v0.1.0

문항별 배점과 예상 정답률만 입력하면, NEIS "추정분할점수 산출관리"에
그대로 복붙할 수 있는 15칸 표를 자동 생성합니다.

다운로드
Windows .exe 설치 파일 macOS (Apple Silicon) .dmg macOS (Intel) .dmg Linux .AppImage

설치 시 보안 경고 안내

개인 개발자가 제작한 무료 소프트웨어로, 상용 코드 서명이 없습니다. 경고가 표시되지만 정상적인 앱입니다.

Windows
  1. "Windows의 PC 보호" 화면에서 "추가 정보" 클릭
  2. "실행" 클릭
macOS
  1. "확인되지 않은 개발자" 경고 시 시스템 설정 > 개인정보 보호 및 보안 이동
  2. 하단 "확인 없이 열기" 클릭

주요 기능

1PL Rasch 모델정답률만 입력하면 자동 계산
NEIS 복사15칸 값을 한 번에 복붙
자동 업데이트새 버전이 나오면 앱에서 알림
완전 오프라인시험 데이터가 외부로 전송되지 않음

업데이트

설치 후에는 앱 내에서 자동 업데이트가 지원됩니다. 새 버전이 나오면 앱 상단에 알림이 표시되며, 클릭 한 번으로 업데이트됩니다.
