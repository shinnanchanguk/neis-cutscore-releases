# 추정 분할 점수 계산기

교사가 문항별 배점·난이도·예상 정답률을 입력하면, NEIS에 그대로 복붙할 수 있는 15칸 표를 자동 생성하는 데스크톱 앱입니다.

Made by [DoRm](https://dorm-green.vercel.app/)

## 다운로드

[최신 버전 다운로드 →](https://github.com/shinnanchanguk/neis-cutscore-releases/releases/latest)

| OS | 파일 |
|---|---|
| Windows | `NEIS._x.x.x_x64-setup.exe` |
| macOS (Apple Silicon) | `NEIS._x.x.x_aarch64.dmg` |
| macOS (Intel) | `NEIS._x.x.x_x64.dmg` |
| Linux | `NEIS._x.x.x_amd64.AppImage` 또는 `.deb` |

## ⚠️ 설치 시 보안 경고 안내

이 앱은 개인 개발자가 제작한 무료 소프트웨어로, 상용 코드 서명 인증서가 없습니다.
설치 시 보안 경고가 표시되지만 **정상적인 앱**입니다.

### Windows
1. "Windows의 PC 보호" 화면이 나타나면
2. **"추가 정보"** 를 클릭합니다
3. **"실행"** 버튼을 클릭합니다

### macOS
1. "확인되지 않은 개발자" 경고가 나타나면
2. **시스템 설정 > 개인정보 보호 및 보안** 으로 이동합니다
3. 하단에 차단된 앱 안내가 있으면 **"확인 없이 열기"** 를 클릭합니다

## 업데이트

설치 후에는 앱 내에서 **자동 업데이트**가 지원됩니다.
새 버전이 나오면 앱 상단에 알림이 표시되며, 클릭 한 번으로 업데이트됩니다.
